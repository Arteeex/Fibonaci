# Fibonacci

Простая программа на Rust для вычисления числа Фибоначчи.

## Как работает
1. Программа просит ввести порядковый номер числа.
2. Вычисляет число Фибоначчи с помощью цикла `for`.
3. Выводит результат на экран.

## Запуск

```bash
cargo run
```

## Пример

```text
Введите порядковый номер числа Фибоначи
7
Число фибоначчи для 7 равно 13
```
